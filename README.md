# chen1

个人学习练习仓库（C++ / ROS）。

## 目录结构

```text
.
├── task1
│   └── environment        # 配置环境
├── task2
│   ├── cpp
│   │   ├── 1              # 入门一
│   │   └── 2              # 入门二
│   └── ros                # 分支结构
└── README.md
```

## 内容说明

| 目录 | 说明 |
| --- | --- |
| `task1/environment` | 开发环境配置：VMware + Ubuntu 虚拟机、Visual Studio 2022 等 |
| `task2/cpp/1` | C++ 入门练习一：第一个 Hello world 程序 |
| `task2/cpp/2` | C++ 入门练习二 |
| `task2/ros` | ROS 相关练习 |
